# nirakar-sakar-vedanta-quantum-duality
Two research essays reconciling Nirakar (formless) and Sakar (form) views of the divine in Hindu philosophy, using causal cosmology, Puranic symbolism, and a quantum wave-particle duality model, called Monistic Polymorphism, to unify Advaita Vedanta, Puranic theology, and modern physics. Includes a dark-mode HTML explainer.
